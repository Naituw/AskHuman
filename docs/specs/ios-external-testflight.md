# iOS 朋友外部 TestFlight

2026-11-05。用户批准的[开发计划](../plans/ios-external-testflight.md)对应的实现契约。

## 范围

首批 1–5 位开发者朋友，各用自己的 Mac、Agent 和 EMQX。维护者提供现有中继。
通过外部 TestFlight 邮件邀请，无公开加入链接，不给朋友 App Store Connect 角色。
首轮不做演示模式，审核说明如实列出 Mac、MQTT 与中继依赖，先尝试 Beta 审核。
如果审核要求可用账号或演示环境，再由用户决定应对方案。

## 分发与资料

- 原内部流程保持默认；Python 与 Swift 均只接受 `internal` / `external`。外部模式只改临时导出选项，持久配置仍必须 internal-only。
- 外测构建必须 `VALID`、未过期、`APP_STORE_ELIGIBLE`、出口加密声明已解决。已有 `INTERNAL_ONLY` 构建不能转用。
- 中英文隐私政策和接入指南来自四份显式公开文档，构建脚本清空专用输出再渲染；仅手动 Pages 发布。
- Macs 页「关于」按 App 语言打开隐私 / 接入链接。首次外测交付前必须核实实际 HTTPS 页面可达。
- 测试描述、审核步骤、联系人与构建测试说明各有归属；审核电话、朋友邮箱与中继私有配置不进公开 git。
- 联系人恢复是显式只读操作；其他应用只查询联系人、反馈邮箱和公开链接，不获取演示密码或审核备注。

## 受限写入

`ExternalTesting.swift` 接收封闭的 JSON 请求；认证仍在稳定签名 helper 内。
应用固定为 `6828712684`，组固定为 `AskHuman Friends`；不接受任意 URL、应用 ID、DELETE 或用户/角色管理。

| 模式 | 写入边界与验收 |
|---|---|
| metadata | 仅 en-US / zh-Hans Beta 描述、反馈和页面链接，以及本应用审核联系人 / 无演示账号声明 / 备注；差异更新，完整读回 |
| group | 私密外部组、手动分配构建；分配前关闭并读回自动通知；已有测试者时拒绝加入新的构建 |
| submit | 构建已分配、资料齐全、状态允许才提交；已排队 / 已审核不重复提交，结果读回 |
| invite | 审核已通过；仅指定邮箱，首批总量 ≤5；验证邮箱一致性，复用既有 tester，只改本组；NOT_INVITED 才发指定 tester + app 的邮件，读回邀请状态 |

所有修改操作与上传共用独占锁。资源 ID 验证后才进入固定路径；只访问 Apple HTTPS 源，拒绝重定向。
无自动重试、无失败后自动回滚；出错先读现状。列表超过一页（200）拒绝继续，不把部分数据当完整名单。
请求进入 helper 前放到用户专属临时目录的 0600 文件，退出清理；调用者自己的输入文件由调用者保管和清理。
联系人结果属于私有材料；错误日志不输出 token / 私钥 / 请求体。

## 完成条件

上传成功、可外测、送审、获批、邀请、接受、安装、实际接入是不同状态。
邀请操作只证明 Apple 的邀请状态；首位朋友仍需安装、配对、前台问答与锁屏生产推送验证。
源码用统一本地 `ios-testflight-N` 标签记录；外测构建被 Apple 接受后即留源码基线，审核/交付状态另记。
平台拒绝、法律条款、联系方式冲突以及用户要求确认的 Pages 启用都要交回用户；没有请求不新建监控自动化。

## 验证与运维

`scripts/ios-testflight-external.node-test.mjs` 编译真实 Swift 规则并注入伪 Apple transport，覆盖默认内部 /
显式外部、资料幂等读回、范围限制、分组通知闸门、审核状态、五人上限、复用测试者、邀请去重和失败状态。
旧 changes / notes / archive preflight 回归一起运行。真实 Apple 核验通过已安装 helper 只读操作完成；
未获批准的邀请不作为测试。操作命令与修复边界见[外测手册](../../.agents/skills/ios-testflight/references/external-testing.md)。
