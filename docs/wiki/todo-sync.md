# iCloud 待办同步

> 适用于包含同步组件的新版本；已发布的 v0.16.0 尚不包含此功能。
> [English](todo-sync.en.md)

iCloud 同步让同一 Apple ID 下的多台 Mac 共享项目待办和执行历史。它是实验性功能，默认关闭，
需要 **macOS 14 或更新版本**。AskHuman 的其他功能仍支持 macOS 11 起。

## 开启

1. 在每台 Mac 上通过 `npm install -g askhuman` 安装或更新 AskHuman。
2. 打开设置，开启「实验性功能」，进入「实验 → 待办存储」。
3. 选择「iCloud 同步」。程序会安装随版本携带的同步组件，无需单独下载或安装 Xcode。
4. 如果系统要求批准后台项，点「打开系统设置」，在「通用 → 登录项与扩展」允许
   **AskHuman Todo Sync**，回到 AskHuman 点「修复」。
5. 在其他 Mac 上登录同一 Apple ID，并分别开启同步；等首次同步完成。

普通用户不需要 Apple 开发者账号、CloudKit Dashboard 或配置服务密钥。每个 Apple ID 的待办
存放在自己的 iCloud 私有数据库中；不同 Apple ID 之间不共享待办。

## 会同步什么

- 有 Git remote 的项目按规范化后的仓库地址匹配。同一仓库的多个目录 / worktree 是同一份待办的副本。
- 待办文字、顺序、完成 / 恢复 / 删除与执行历史跨机同步。
- 没有 remote 的目录仍是「仅本机」。其他 Mac 有、本机尚无目录的项目也可以在待办窗口查看与编辑。
- **附件文件不同步**，其他设备只看到附件所在设备的提示；⚡ 自动执行标记也不跨机。
- **清空项目执行历史会影响所有 Mac 与 iCloud 中的该项目历史**；确认框会说明范围。
  「从 iCloud 移除此项目」也会删除该项目在所有 Mac 上同步的待办与历史。

## 同步需要多久

后台通过 iCloud 推送和定期轮询更新，可能需要几十秒，有时更久，不保证秒级到达。
打开待办窗口、重新聚焦窗口会在后台刷新，也可以点击「立即同步」。

What's next 在上次成功拉取超过 20 秒时尝试刷新，最多额外等 1.5 秒。超时或离线时使用
本机数据，并在后台补拉；已经出现的卡片不会因为后来的同步而改变选项。

断网时本机照常添加、编辑和读取待办，联网后再合并。请等另一台显示同步完成后再据此判断
它已经收到某条新待办。

## 停止与账号变化

「停止同步（保留本机副本）」不会删除本机或 iCloud 待办；再次开启只合并差异。
「清除 iCloud 中的待办数据」会清除整个云端待办区并让其他 Mac 暂停，需要特别确认。

如果这台 Mac 更换 Apple ID，程序暂停同步，避免把旧账号的数据自动上传到新账号。
确认账号与数据范围后再选择后续操作；不确定时先保留本机副本。

## 排障

- **等待后台项批准**：到系统设置允许 AskHuman Todo Sync，返回点「修复」。
- **组件缺失或版本不兼容**：更新 AskHuman，然后点「修复」；npm 更新会携带匹配的组件。
- **未登录或 iCloud 空间不足**：处理系统账号或存储问题后重试。
- **迟迟没有同步**：两台都检查状态并点「立即同步」，确认同一 Apple ID、同一 Git remote、
  网络可用且没有睡眠。

命令行排障：`AskHuman todo-sync status --json`；组件日志位于
`~/Library/Logs/AskHumanTodoSync/helper.log`。不要通过删除 `todos.json` 来修复同步。
