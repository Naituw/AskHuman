# 通用设置

简体中文 | [English](./settings.en.md)

运行 `AskHuman --settings`（或在弹窗右上角点齿轮）打开设置界面，分三个 Tab：**通用**、**Agents**、**通信渠道**。本文介绍「通用」相关偏好；Agents 集成见 README 的「集成到 Agent 中」，渠道接入见 README 的「配置沟通渠道」。

## 通用

- **主题**：跟随系统 / 浅色 / 深色。
- **窗口置顶**：让弹窗始终保持在最前。
- **出现动画**（仅 macOS）：None / Document / Alert。
- **窗口材质**（仅 macOS）：macOS 11–25 可选纯色 / 模糊，macOS 26+ 还可选玻璃。默认为模糊；纯色完全不透明；旧系统读取到旧配置的玻璃值时会自动使用模糊，不改写配置。
- **语音输入**（仅 macOS）：识别语言与触发快捷键。
- **回复历史保留条数**：默认 200；设为 `0` 则停止新增并清理已有记录。当已有条数超过上限时，会出现「立即清理」按钮可立刻裁剪。

## 作答窗口

打开设置，在「通用 → 弹窗行为」的第一项 **提问窗口模式** 中切换，默认选用**合并窗口**。
也可通过设置搜索输入「合并」「独立」「窗口模式」或「Sidebar」直接定位该选项。
多个 Agent 的提问在同一个窗口中按项目分组，点击左侧列表切换；每个提问的草稿独立保留，全部回答后窗口隐藏。

选择**独立窗口**可以恢复每个提问一个窗口的方式。修改从新提问开始生效，已经打开的提问和草稿继续留在原窗口。两种模式共用「弹窗预热」开关。

## 回复历史

每次在弹窗或任一渠道完成的「发送」与你主动「取消」都会记录到本地，方便回答新问题时参考。系统触发的取消（超时 / 断连 / daemon 停止）不记录。

- **打开**：`AskHuman --history` 默认当前项目，`--all` 查看全部项目；也可在弹窗右上角点「历史」。从弹窗进入时，如果当前 Agent 会话已有历史，会自动展示该会话跨项目的全部记录；否则回到当前项目。
- **项目识别**：从命令运行目录向上找首个 `.git` 仓库根；没有 `.git` 则用当前目录。
- **筛选**：用一个两级范围菜单先选项目，再从子菜单选「本项目全部」/「所有会话」或单个会话；还可叠加多个空格分隔的关键词。真实 Agent 会话显示标题与短 ID；没有真实会话时，MCP 连接会明确标成近似会话。
- **清理**：菜单会按当前上下文显示「删除当前搜索结果」「清空所选会话的记录」或「清空所选项目的记录」，只删除确认时冻结的记录；确认后新出现的匹配记录会保留。「清空全部历史」始终独立，在全量范围无搜索时只显示这一项。

## 快捷回复

弹窗页脚的 **快捷回复** 按钮（⌘K / Ctrl+K）列出一组预设回复：点一行，或按数字键 1–9（第 10 条按 0），**立即发送**。已经回答的问题保持你的答案，还没有答案的问题都收到这一句；所有问题都答完时预设置灰。What's next 和「只能选择」的提问没有预设。手机的回答页底栏也有同样的菜单，点一下就发送；预设按提问所属那台 Mac 的设置，手机上不编辑。

在 **设置 → 通用 → 快捷回复**（或菜单底部的「管理快捷回复…」）里编辑：

- 出厂有 5 条（「继续」「按你的判断来，不用等我」……），随界面语言；改动其中任意一条后，这份列表就归你自己了。
- 每行一个输入框，失焦保存；清空即删除；拖动左侧把手（或在把手上按 ↑ / ↓）排序；最多 10 条，每条最多 200 个字符；「恢复默认」回到出厂列表。

## 离开模式与「本会话不再使用」

菜单里的另外两条是**指令**，不会立刻发送，而是先放在输入区上方，等你点「发送并…」才随这次回答生效。

- **离开模式**：开启后，Agent 的提问和 What's next 由 AskHuman 自动回复，引导它围绕你的原目标继续、自己处理常规选择，明确的任务范围仍有效。原目标真正完成或剩余工作确实无法继续时，Agent 通过 `--escalate "理由"`（MCP：`escalate: "理由"`）联系你；理由会显示在报告最前面，弹窗、手机、IM 和历史一致。旧布尔值或空理由会收到补充指引；连续三次无有效理由后，第四次会以「系统兜底放行」送达，并注明没有 Agent 理由。升级不会结束离开模式。范围可选「所有 Agent」或「仅此会话」，备注会一直附在自动回复后面；每条自动回复都记入历史。
  - **看得见**：托盘图标带月亮、控制台顶部有提示条、macOS 上屏幕顶部居中有一个桌面胶囊（悬停或点击展开，可拖动，设置里可关）、手机 App 的标签栏上方有橙色条。
  - **开启**：菜单里的「离开模式…」、托盘菜单、控制台会话页头的「AskHuman」、手机 Agents 页的月亮按钮、命令行 `AskHuman away on [备注] [--session]`、IM 里的 `/away [备注]`。
  - **结束**：只有你能结束——弹窗顶部的「结束离开模式」、托盘、控制台、胶囊、手机上的「结束」、`AskHuman away off`（Agent 进程里被拒绝）、IM 的 `/back`。macOS 上离开期间空闲 5 分钟后再操作电脑，会弹出「欢迎回来」摘要，只提醒、不会自动结束。
  - **设置 → 通用 → 离开模式**：桌面胶囊、回到电脑时的提醒，以及「推送到手机的等待时间」（默认 Mac 空闲 1 分钟；取它与 iOS 渠道自己的推送时机里较短的那个）。
- **本会话不再使用 AskHuman**：这次回答会告诉 Agent「用户选择不再使用，后续不要再用」；之后这个会话再调用 AskHuman（含 `--whats-next`）会立刻得到同样的提示，Stop 确认也不再打扰。权限审批与出错通知照常。要恢复，在托盘的 Agent 子菜单、控制台会话页头的「AskHuman」菜单或手机的会话行里取消「不再使用」即可：下一次工具调用时 Agent 会读到一句「可以继续使用 AskHuman 了」（经插话队列送达，不会向原会话发消息，也就不会触发新一轮计费）。

Stop 确认、权限审批、出错卡与 Codex 原生问题的窗口里没有这个按钮，也不受离开模式影响。

## Cursor Desktop 后台完成续跑

macOS 的「Agents → Cursor」集成卡提供 **禁止后台完成后自动续跑（实验）**，默认关闭，仅 CLI/MCP
自动集成有效时可用。它对所有本地 Cursor Desktop 会话生效，不限于调用过 AskHuman 的会话。
后台命令和子代理照常运行并保留结果；完成通知不再自动启动一轮模型，需主动发送消息继续。
正在执行的 Await 仍可取得结果，另设的 Goal、订阅和定时调度不受此开关控制。终端 Cursor CLI
不在范围内。

开启后 AskHuman Daemon 保持运行，自动接入已打开及以后启动的 Cursor 窗口；设置显示等待、
接入、已生效或失败。需要兼容的 Cursor 版本，检查通过才生效；不匹配时保持原生行为并显示失败。
启动/重载期间存在短暂接入过程，不需要修改 Cursor 的启动方式，也不承诺升级后始终兼容。
关闭开关或切至未集成会恢复原生行为，已确认的旧通知不回放；原聊天不会被归档或隐藏。
手动停止 Daemon 后，已接入窗口的拦截可能继续驻留；要恢复原生续跑行为，应关闭本开关或
切至未集成。可用 `AskHuman doctor --json` 查看 `cursorDesktop` 诊断。

## 新建 Cursor 任务

**运行位置。** 「Agents → Cursor」集成卡的「新任务运行位置」可选 CLI（默认）或 Agents 窗口（实验，仅 macOS）。
选 Agents 窗口后，GUI、IM `/new` 与手机新建的 Cursor 任务会在你已打开的 Cursor Agents 窗口里创建会话并自动发送；
需要 Cursor 正在运行、只有一个 Agents 窗口，且项目已添加到其中。创建前窗口不可用时，新任务改用 CLI，集成卡状态行会说明原因；
任务一旦在 Agents 窗口里开始，失败也不会再自动改用 CLI。

**Max 模式。** 仍在旧的按次计费计划里的用户，Max 按 API 费率计费、额度消耗很快，所以 AskHuman 新建 Cursor 任务时
默认强制关闭 Max（「高级 → Cursor 任务的 Max 模式」）：

- 新建任务窗口与手机新建页里的「允许 Max」默认关闭，每个任务单独选择、不会保存；打开后按 Cursor 默认行为运行。IM `/new` 没有开关，按默认策略执行。
- Cursor 模型列表会标出每个模型是否需要 Max。需要 Max 的模型在不允许 Max 时不会启动，并提示换用不需要 Max 的模型，或本次打开「允许 Max」；无法判断时照常启动并提示，启动后再复查。
- CLI 路线通过关闭 CLI 的全局 Max 开关实现，这是全局粘性设置：之后手动运行 CLI 也保持关闭，直到你用 `/max-mode` 重新打开。Agents 窗口路线只作用于这次创建的会话。
- 启动后若发现 Max 又被打开，会弹出一张普通提问卡提醒。
- 策略可改为「沿用 Cursor 当前设置」，此时不干预、不拦截、不提示。新计划（按用量计费）没有 Max，计划类型自动检测，也可手动指定；新计划下所有相关界面都会隐藏，也不会改动 Cursor 的设置。

## Codex MCP 环境变量

可显式运行 `AskHuman agents mode codex mcp --env DISPLAY=:1` 配置 MCP server 环境变量。`--env NAME=VALUE` 可重复；同名变量以最后一次为准，值可为空或包含 `=`。变量名不可为空或包含 `=`、NUL，值不可包含 NUL。仅 Codex MCP 模式支持该选项。安装和更新保留未指定的环境变量；Claude/Cursor 更新也保留已有 JSON `env`。无效环境配置会中止写入。此行为需主动启用，不会自动注入桌面环境变量。
