# iOS 渠道的 Broker：要求、选择与验证

简体中文 | [English](./ios-broker.en.md)

AskHuman 的 iOS 渠道用一个 MQTT broker 在 Mac 和 iPhone 之间中转消息。broker 由你自备，AskHuman 不代管也不转售。消息是端到端加密的，broker 只看得到密文和「谁在线」这类元数据（见 [iOS App 渠道配置](./ios-setup.md#它怎么工作以及谁能看到什么)）。

下面先列对 broker 的**要求**，再并列三条**已经实测**的路径：EMQX Cloud Serverless、flespi、自建 Mosquitto。任何满足要求的 MQTT broker 都能用，拿仓库里的[兼容套件](#怎样自己验证)跑一遍就知道。

## 对 broker 的要求

| 要求 | 原因 |
|---|---|
| MQTT 3.1.1，clean session，QoS 1 | Mac 和手机都用这一组合收发消息 |
| 保留消息，以及 **QoS 1 的保留遗嘱** | 「在线 / 离线」用保留消息表示；Mac 被强杀或断网时，由遗嘱把它改成离线 |
| 单条消息至少约 1 MB | App 发出的单条加密信封最大 900,000 字节；broker 的包大小上限更低就会丢消息或断开连接 |
| 用户名 + 密码（固定的），用户名只含字母和数字 | 用户名同时是话题命名空间 `ah/<用户名>/`，Mac 和手机共用同一份凭据 |
| 同一个用户名可以同时开多个会话 | Mac、手机（以及更多台 Mac）同时在线 |
| 公共 CA 签发的 TLS 证书，默认端口 8883 | App 不接受自签证书 |
| （可选）WSS，路径 `/mqtt`，默认端口 8084 | 网络封掉 8883 时的备选；TLS 连不上时才会尝试 |
| 账号隔离：一个账号只能读写 `ah/<自己的用户名>/#` | 多人共用同一个 broker 时必须有；一个人自用不隔离也能工作 |

## 三条路径对比

数据取自 2026-11-21 的实测和官方页面，第三方服务的价目与条款会变，以官方页面为准（链接在各节）。没测的格子写「未测」。

| | EMQX Cloud Serverless | flespi | 自建 Mosquitto |
|---|---|---|---|
| 服务器位置 | 你选的区域（作者的实例在杭州） | 欧洲 | 你自己的服务器 |
| 端口 | TLS 8883；WSS 8084 | TLS 8883；WSS 443 | 自定；证书须由公共 CA 签发 |
| 凭据 | 控制台里建用户名 / 密码 | 用户名 = token 编号，密码 = 完整 token | `mosquitto_passwd` |
| 账号隔离 | 按下文配置 ACL | 每个 token 的 ACL 限定到 `ah/<编号>/#` | `pattern readwrite ah/%u/#` |
| 免费额度 | 每月 100 万连接分钟、1 GB 流量 | Free 套餐：官方限制表按速率和存储限制，没有每月流量上限一项；官方定位「测试与开发」，额度不可扩展 | 无（服务器自付） |
| 超出免费额度 | 部署停止，之后要在控制台手动启动；继续使用要先充值 | 超速的 token 暂停 1 分钟；保留消息存储满后不再保存新的保留消息 | — |
| 门槛 | 继续用到免费额度之外要预充值，作者所知最低 ¥100（官方文档未写明） | 付费套餐 €130/月起；免费账号 60 天无活动会被删除 | 一台有公网地址的服务器、域名和证书 |
| 大陆访问（作者网络，单次测量） | 国内实例：QoS 1 发布到收到确认，TLS 约 136 ms，WSS 约 35 ms | 跨境：QoS 1 发布到收到确认约 315 ms，建连 0.5–1 s | 取决于你的服务器 |
| 大陆多地拨测（单次抽样，周六 21:00，329 个探测点，其中家宽 292 个） | 响应时间中位约 33–36 ms | 8883 与 443 约 96% 可达；中位约 205–290 ms；约 3.5–4.3% 超时；约 10–13% 的家宽探测慢于 0.9 s | 取决于你的服务器 |
| 兼容套件结果 | TLS、WSS 全部必须项通过；1 条警告（见下） | TLS、WSS 全部必须项通过，无警告 | TLS、WSS 全部通过，无警告 |
| 已知差异 | WSS 下 `DISCONNECT` 后 broker 仍会发布遗嘱（无害，见下）；连接静默中断约 45 秒后发布遗嘱 | 连接静默中断约 90 秒（3 倍 keepalive）后才发布遗嘱 | 连接静默中断约 46 秒后发布遗嘱；证书和反向代理要自己维护 |

表里「大陆访问」一行是作者在中国大陆、不经代理的网络上测的，只能说明那一刻、那一条线路的情况；「大陆多地拨测」一行来自站长之家的多地端口检测，也只是一次抽样。

## 路径一：EMQX Cloud Serverless（托管）

兼容套件结果（Cloud Serverless，杭州，2026-11-21）：TLS 与 WSS 的必须项全部通过，账号隔离通过；唯一的警告是 WSS 下干净断开后 broker 仍发布遗嘱（见下）。

### 配置

1. 在 [EMQX Cloud](https://cloud.emqx.com/)（国内站）创建一个 **Serverless** 部署，**消费限额保持 0**（默认值，只用免费额度）。国际站是 [cloud-intl.emqx.com](https://cloud-intl.emqx.com/)，它的价目以其官网为准，本文数字取自国内站。
2. 在部署的「概览」里记下**连接地址**。端口：TLS `8883`，WSS `8084`。
3. **认证**（「访问控制 → 客户端认证」）：添加一个用户名 / 密码，用户名只用**字母和数字**。
4. **授权（ACL）**（「访问控制 → 客户端授权」）。这个页面默认是**黑名单模式：没被明确拒绝的请求一律放行**，所以第 1 条兜底**必须有**，否则任何账号都能读写别人的话题：
   1. 切到「全部用户」标签，添加：话题 `#`，动作「发布 & 订阅」，**不允许**（兜底）。
   2. 切到「用户名」标签，添加：上一步的用户名，话题 `ah/<用户名>/#`，动作「发布 & 订阅」，**允许**。EMQX 先看这个账号自己的规则，再看「全部用户」规则，所以只有自己的话题放行。
5. 把主机、端口、用户名、密码填进 AskHuman（见 [iOS App 渠道配置](./ios-setup.md#四在-mac-上启用)），再[跑一遍兼容套件](#怎样自己验证)确认隔离生效。

### 免费额度与用量

- 每月免费：**100 万连接分钟、1 GB 流量**（所有流入和流出部署的公网流量；一条消息发布和投递各算一次）、100 万规则动作（AskHuman 用不到）。超出后的价格：连接 ¥8 / 百万分钟，流量 ¥1.5 / GB（官方价目，[产品计费](https://docs.emqx.com/zh/cloud/latest/price/pricing.html)）。
- 看用量：部署的「概览」页显示本月连接分钟和流量，统计间隔 1 小时，显示会滞后约 1 小时；用到免费额度的 75% 时，EMQX 会给账号邮箱发提醒（[部署相关问题](https://docs.emqx.com/zh/cloud/latest/faq/deploy.html)）。
- AskHuman 自己也显示本月流量（本机统计，Mac 设置页和手机的「Mac」页），每到接近一个 GB 时提醒一次。附件是流量的大头：手机打开一张约 2 MB 的大图，在 broker 上要计约 7 MB。

### 缺点

- **超出免费额度要先充值。** 消费限额为 0 时，连接分钟或流量任一用尽，部署就停止，App 会提示「Broker 拒绝了连接，可能是本月的免费额度用完了」。想在当月继续用，要提高消费限额，而这需要账户里有余额。**作者所知，充值最低 ¥100**；EMQX 的官方文档没有写明最低充值额，以控制台充值页的提示为准。
- **停止之后不会自己恢复。** 下个月拿到新的免费额度后，或者提高消费限额后，部署都不会自动启动，要在控制台手动启动。
- **长期不用会被回收。** 连续 30 天没有活跃客户端，系统会停止部署；停止后再过 30 天没启动，可能被删除，删除后不能恢复（[创建 Serverless 部署](https://docs.emqx.com/zh/cloud/latest/create/serverless.html)）。
- 连接分钟一般不是问题：一个全天在线的连接一个月约 4.3 万连接分钟，Mac 加手机也远低于 100 万。要留意的是流量。

### WSS 下 DISCONNECT 后的遗嘱

兼容套件在 EMQX 的 WSS 上给出一条警告：客户端发了 `DISCONNECT` 并立即关闭 WebSocket 时，broker 仍会把遗嘱发布出去（3 次里 3 次；发完 `DISCONNECT` 等 300 毫秒再关闭，2 次里 0 次；TLS 上 6 次里 0 次）。MQTT 规范说这时不应发布遗嘱。对 AskHuman 没有影响：Mac 和手机在主动断开前，都会先自己发布一条保留的「离线」，所以最多多一条重复的「离线」，状态不会错。

## 路径二：flespi（托管，欧洲）

兼容套件结果（Free 套餐，2026-11-21）：TLS 与 WSS 的必须项全部通过；使用下面的窄 ACL 时，账号隔离与两个账号互验也通过；无警告。

### 配置

1. 在 [flespi.io](https://flespi.io/) 注册账号，保持 **Free** 套餐。
2. 左侧菜单「Tokens」，右下角「+」新建 token：
   - **类型选 ACL**。ACL 里只留一条：模块 `mqtt`，动作 `publish` 和 `subscribe`，主题先写 `ah/#`（创建后马上改成窄规则）。
   - **TTL（有效期）要填**：flespi 不允许没有期限的 token。填面板允许的最大值 **8760 小时（一年）**。TTL 从最近一次使用起算，只要有 MQTT 会话在线就算使用，Mac 一直在线的话不会过期；整整一年没用，token 会被删除且不能恢复，那时要新建 token 并更新两端设置（[Tokens 说明](https://flespi.com/kb/tokens-access-keys-to-flespi-platform)）。
3. 新建后，token 列表里每个 token 左上角有一个 `#` 开头的**编号**。**打开这个 token，把 ACL 的主题改成 `ah/<编号>/#`**（点「Show JSON」可以直接改 `acl` 数组：`[{"uri":"mqtt","actions":["publish","subscribe"],"topic":"ah/<编号>/#"}]`），保存。flespi 的 ACL 是默认拒绝的，只放行这一条，账号隔离就成立了。
4. 在 AskHuman 里填：

   | 字段 | 填什么 |
   |---|---|
   | Broker 主机 | `mqtt.flespi.io` |
   | TLS 端口 | `8883` |
   | WSS 端口 | `443` |
   | 用户名 | token 的**编号**（只有数字） |
   | 密码 | **完整的 token**（只有新建时能拿到完整内容，当场复制；之后列表里是打码的） |

   flespi 的官方示例把 token 放在用户名里，但它也允许放在密码里（[MQTT API 页](https://flespi.com/mqtt-api)）。AskHuman 的用户名同时是话题命名空间，所以用「编号做用户名、token 做密码」：作者实测这样可以连接，用户名填别的内容会被拒绝。
5. [跑一遍兼容套件](#怎样自己验证)确认通过。

> flespi 的 ACL 在**投递层**生效：订阅和发布都会返回成功，但跨账号的消息永远不会投递。兼容套件按这个标准判断，看到「accepted, then dropped at delivery」是正常的。

### 免费额度与用量

- Free 套餐没有每月流量上限，限制是速率和存储：同时在线的会话 50 个（Mac 和手机各占一个）、每个会话 200 个订阅、每分钟 2 万条消息、保留消息存储 100 MiB、会话存储 100 MiB、REST / MQTT 流量每分钟 50 MiB（超了该 token 暂停 1 分钟）。官方说明这些额度**不可扩展**（[限制文档](https://flespi.com/docs/flespi_en_restrictions.pdf)，2026-08-12 发布的版本；[价目](https://flespi.com/pricing)）。
- 看用量：登录面板，首页（Dashboard）的「MQTT」卡片显示会话数、消息数和保留消息存储，「Total traffic」卡片按 1 小时 / 24 小时 / 7 天 / 30 天 / 1 年显示流量；也可以通过 API 查看。
- AskHuman 自己显示的本月流量只统计这台设备的消息。

### 缺点

- **免费套餐定位是「测试与开发」。** flespi 可以单方面修改限制条款（修改自公布起至少 25 天后生效）。付费的 Commercial 套餐 €130/月起，没有更便宜的档位（[价目](https://flespi.com/pricing)）。
- **免费账号 60 天没有活动会被删除**（可以用同一个邮箱重新注册）。
- **服务器在欧洲，跨境延迟高。** 作者的网络上，QoS 1 往返约 315 ms，建连约 0.5–1 s，900 kB 的消息传完要 1.6–8.5 s（多次测量）。站长之家的多地拨测里，约 3.5–4.3% 的探测点超时。
- 连接**静默中断**（没有任何数据包，也没有关闭）要约 90 秒才会发布遗嘱，是 keepalive 的 3 倍；Mac 进程被杀、TCP 直接断开时，遗嘱 0.3–0.9 秒就发布。
- 客户端在 WSS 上不发 `DISCONNECT` 就直接关闭 WebSocket 时，flespi 不发布遗嘱。AskHuman 总是先发 `DISCONNECT`，不受影响。

## 路径三：自建 Mosquitto

参考配置和逐步说明在仓库的 [`ios/Tools/broker-probe/examples/mosquitto/`](../../ios/Tools/broker-probe/examples/mosquitto/README.md)：一份 `mosquitto.conf`、一行 `pattern readwrite ah/%u/#` 的 ACL 文件，以及安装、加用户、证书、开放端口的步骤。

要点：

- 账号隔离只靠一行规则：`pattern readwrite ah/%u/#`，每个用户自动只能访问自己的命名空间，加新用户不用改规则。
- 证书必须是公共 CA 签发的（例如 Let's Encrypt）；证书续期后给 Mosquitto 发 `SIGHUP` 即可重新加载，不必重启。
- 参考配置同时开了 TLS 8883 和 WSS 8084（路径 `/mqtt`）。不需要 WSS，就删掉后一个监听；App 里的 WSS 端口保持默认值即可，TLS 能连上时不会用到它。

兼容套件结果（Mosquitto 2.1.2，macOS，Homebrew 安装，用临时自签 CA，2026-11-21）：TLS 与 WSS 全部通过，账号隔离和两个账号互验通过，无警告；连接静默中断约 45.6 秒后发布遗嘱；客户端不发 `DISCONNECT` 就关闭 WebSocket 时不发布遗嘱（无影响）。**没有测**：Linux 发行版的安装包，以及反向代理（nginx、Caddy 等）后面的部署；放在代理后面时，把代理的读超时调到 90 秒以上。

## 怎样自己验证

**日常自检：** 设置页 iOS 渠道卡里的「测试连接」（命令行是 `AskHuman channel test ios`）会连上 broker，给自己发一条测试消息并等回声，然后向自己命名空间之外的一个随机话题发一条非保留消息；约 1.5 秒内收到回声，就警告「这个账号能读写自己话题之外的主题」。被拒绝、被丢弃和被断开连接都算已隔离。警告不挡保存与配对。它只查这一项；查得全的是下面的兼容套件。

仓库里的兼容套件对任何 broker 都适用：它按 App 的方式（MQTT 3.1.1，TLS 和 WSS）连接，检查上面「要求」里的每一项，最后给出 `COMPATIBLE`、`COMPATIBLE (with warnings)` 或 `NOT COMPATIBLE`。

```bash
git clone https://github.com/Naituw/AskHuman && cd AskHuman/ios/Tools/broker-probe
npm ci                       # 需要 Node 22.12 或更新版本
# 密码只从环境变量读，不进命令行，也不会被打印
AH_PROBE_PASSWORD='…' node compat.cjs --host <broker 主机> --user <用户名> --port 8883 --ws-port 8084
```

- `--ws-port` 不写就不测 WSS（flespi 填 `443`）。
- `--user2 <另一个用户名>`（密码放在环境变量 `AH_PROBE_PASSWORD2`）会再验证「两个账号互相读不到对方的话题」。
- `--slow` 多测约两分钟，量出连接静默中断后多久发布遗嘱。
- `--markdown` 输出可以直接贴进文档的表格，`--json` 输出机器可读结果。

结果分三级：**must** 不通过，这个 broker 不能用；**should** 不通过是警告（频道能用，但缺一道保险，或有无害的差异）；**info** 只是测量值。退出码：0 兼容，1 有必须项失败（加 `--strict` 时有警告也算），2 用法错误。

测试用的话题都在 `ah/<用户名>/t/<运行编号>/` 下，不碰你真实 Mac 和手机用的话题，结束时清掉自己发的保留消息。完整跑一遍每个传输约 3 MB 流量，会计入你的免费额度。每项检查的含义见 [`ios/Tools/broker-probe/README.md`](../../ios/Tools/broker-probe/README.md)。

仓库里还有 `acl-check.cjs`，只做账号隔离那一部分，旧的命令继续可用。

## 给朋友用（多人共用同一个 broker）

每个人用独立的账号，且每个账号只能访问自己的 `ah/<用户名>/#`：

- **EMQX**：为每个人新建用户名 / 密码，各加一条自己的 `ah/<用户名>/#` 允许规则；「全部用户」的兜底拒绝不要动。
- **flespi**：每人一个 token，各自的 ACL 限定到 `ah/<自己的 token 编号>/#`。免费账号同时在线的会话上限是 50。
- **Mosquitto**：用 `mosquitto_passwd` 加用户；那一行 `ah/%u/#` 规则已经覆盖所有人。

加完后，用 `--user2` 跑一遍兼容套件确认互相看不到。

## 提交新 broker 的实测结果

带 `--markdown` 跑一遍兼容套件（有 WSS 就带上 `--ws-port`），把表格和日期、broker 的版本或套餐写进 pull request，并给出你引用的数字对应的官方页面（免费额度、端口、区域）。只有这样跑过的 broker，才会在文档里写成「已实测」。
