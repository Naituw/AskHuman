# AskHuman Mobile 朋友内测

[English](../beta/) · [隐私政策](../privacy-zh/)

在 iPhone 上回答自己 Mac 上 Agent 的提问。按下面五步完成配置。

**开始前**：准备一台 Mac、iOS 17 或以上的 iPhone，以及邀请人发来的 **TestFlight 邮件邀请和推送中继地址**。

## 1. 安装 Mac 端

Mac 上未安装 Node.js 时，先安装 [Node.js LTS](https://nodejs.org/zh-cn/download)。然后打开终端执行：

```bash
npm install -g askhuman@latest
AskHuman setup
```

在向导里接入你使用的 Agent；其它聊天工具可以先跳过。完成后重启已打开的 Agent，让接入生效。

## 2. 创建自己的 EMQX

1. 打开 [EMQX 国内站控制台](https://cloud.emqx.com/console/)，注册并登录，新建项目 `AskHuman`。
2. 项目内点「新建部署」，选 **Serverless**，名称填 `askhuman`，**消费限额填 `0`**，其余默认。创建后等到「运行中」。
3. 进入部署，打开「访问控制 → 客户端认证」，添加用户名 `ah01`，自行设置并保存密码。
4. 打开「访问控制 → 客户端授权」，添加两条规则：
   - 「用户名」页：用户名 `ah01`，主题 `ah/ah01/#`，动作「发布 & 订阅」，权限「允许」。
   - 「全部用户」页：主题 `#`，动作「发布 & 订阅」，权限「不允许」；删除已有的允许 `#` 规则。
5. 回到部署「概览」，复制「连接信息」中的 **连接地址**，下一步要用。

消费限额 `0` 只使用免费额度，用完停止部署。见 [EMQX 官方说明](https://docs.emqx.com/zh/cloud/latest/price/pricing.html#消费限额)。

## 3. 填写 Mac 连接信息

终端执行 `AskHuman --settings` 打开设置：

1. 「通用」→ 开启「实验性功能」。
2. 「实验」→ 启用「iOS App 渠道」，填写：

   | 字段 | 填什么 |
   |---|---|
   | Broker 主机 | 上一步的连接地址，只填域名 |
   | TLS 端口 | `8883` |
   | WSS 端口 | `8084` |
   | 用户名 | `ah01` |
   | 密码 | 上一步自行设置的客户端密码 |
   | 推送中继地址 | 邀请人单独发来的完整地址 |

3. 点「测试连接」，确认 **broker 往返和中继检查都成功**。
4. 「高级」→「守护进程生命周期」→ 选「保活」，让手机随时能连接。使用期间保持 Mac 在线、唤醒。

## 4. 安装手机 App 并配对

1. iPhone 安装 [TestFlight](https://apps.apple.com/app/testflight/id899247664)，打开邮件邀请，安装最新 AskHuman，首次打开时允许通知。
2. Mac 的 iOS App 渠道中点「配对新手机」。手机打开「Mac」页 →「添加 Mac」→ 扫描二维码。
3. 核对两边的 **6 位确认码** 一致，在 Mac 点「允许」。二维码过期就重新生成，有效期 5 分钟。

## 5. 测试收答和通知

1. 手机保持 AskHuman 在前台，在 Mac 终端执行：

   ```bash
   AskHuman -q "手机测试：请回复收到"
   ```

2. 在手机回答，确认 Mac 终端收到结果。这条命令只测试收答，不调用模型。
3. Mac 的 iOS App 渠道把「推送时机」暂改为「立即」。锁屏手机，再执行一次上面的命令，点通知进入并回答。

两次都成功就配置好了。测试后可改回喜欢的推送时机；默认要等 Mac 空闲 15 分钟才推送，手机收件箱不受这个等待限制。

遇到问题，把失败页面截图和两端版本号发给邀请人；遮住密码、连接串和配对码。
