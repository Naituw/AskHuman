# AskHuman Mobile 隐私政策

生效日期：2026 年 11 月 5 日

[English](../privacy/) · [内测接入指南](../beta-zh/)

AskHuman Mobile 是你自己 Mac 上 AskHuman 的手机配套端。本政策说明 iOS App，以及 AskHuman 项目维护者为邀请制内测提供的推送中继。你选择的 MQTT 服务商、Apple、Agent 服务商和自行运行的服务另有各自的隐私条款。

## 保存在你设备上的数据

App 处理提问、回答、确认、Agent 信息、任务指令和你选择发送的附件。这些内容可能包含个人或机密信息。已配对设备使用端到端加密交换这些内容；MQTT broker 和我们的推送中继不持有能够解密内容的配对密钥。

iPhone 在系统钥匙串中保存配对凭据和密钥，也会保存请求缓存、草稿、待发送消息、本地回答历史、附件及用量计数。新增历史时会裁剪为最近 90 天内最多 500 条；这不是对所有缓存文件的定时删除承诺。应用文件由 iOS 的设备数据保护机制保护。Mac 会独立保存其 AskHuman 记录。

手机待办界面读取和修改已配对 Mac 上的待办。可选的 iCloud 同步由 Mac 执行，iOS App 不直接访问项目的 CloudKit 容器。新建任务或向 Agent 发消息，会让你自己的 Mac 和 Agent 服务商依其设置与条款处理指令及附件。

## 服务会接收什么

- **你自己的 MQTT broker**：加密消息与附件、broker 用户名、连接标识、话题名称、流量与连接时间，以及建立连接所需的网络信息。该服务由你选择和管理。
- **我们的推送中继**：Apple 推送设备 token、应用标识、推送环境、不透明设备句柄和加密通知内容。服务将其转换为 Apple 推送请求。句柄包含加密的路由信息，180 天后到期，App 可以重新登记。中继不维护用户账号或消息正文数据库。
- **Apple 推送服务**：路由信息和加密通知内容。通知扩展在接收设备上解密摘要；是否在锁屏显示取决于你的 iOS 设置。
- **基础设施服务商**：托管和网络服务商可能处理 IP 地址、请求时间及运行元数据。中继程序自己的日志只记录请求方法、状态和耗时，不记录消息正文、token 或句柄。服务商访问日志和保留期限取决于托管配置；端到端加密不会隐藏全部元数据。
- **TestFlight 与反馈**：Apple 会自动收集崩溃日志和使用信息并与开发者分享，你提交的反馈也会分享，详见 [TestFlight 与隐私](https://www.apple.com/legal/privacy/data/en/test-flight/)。其中可能包含邀请邮箱及测试设备／版本信息。你发送邮件、截图或问题反馈时，我们会接收你主动提供的内容，用于排查和回复。

AskHuman Mobile 没有广告或额外集成的第三方分析 SDK。我们不出售你的提问、回答或附件。内容在已解锁设备上显示，或发送给你选择的 Agent／服务商之后，不在传输端到端加密的保护范围内。

## 你的选择与删除方式

你可以拒绝通知或相机权限，在 iOS 设置中调整权限，并选择要发送的文件。相机用于扫描配对二维码或主动拍照。App 请求设备认证时，它用于确认新 Agent 任务的启动。

你可以在 App 中删除回答历史、解除与 Mac 的配对，或在“Mac”页选择“忘记所有配对”。也请在 Mac 上撤销该手机，尤其当任一设备离线时。这些操作不会删除 Mac、Agent 服务商、MQTT 服务商或 Apple 已保存的记录。删除一条历史不代表所有附件缓存均被删除。卸载 App 会按 iOS 行为删除应用容器数据，但钥匙串配对信息可能在重装后保留；不希望恢复时，请先忘记配对再卸载。

要停止使用我们的中继，可以修改或移除 Mac 的 iOS 渠道中的中继地址，并解除手机配对。无状态的路由句柄不是中心化管理的用户账号。需要处理你曾发送给我们的反馈时，请联系维护者并提供足以定位该反馈的信息。不要把密码、配对码、私钥或机密 Agent 会话放入公开问题。

## 联系方式与变更

可通过 TestFlight 邀请中显示的反馈邮箱，或[项目的问题反馈页面](https://github.com/Naituw/AskHuman/issues)联系 AskHuman 项目维护者。公开问题会被其他人看到。数据处理方式变化时，我们会更新本页，并在页首注明生效日期。
