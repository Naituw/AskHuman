### 新增与改进

- **历史附件**：历史详情支持右侧附件预览，并可按有无附件和文件后缀筛选记录。
- **作答窗口**：可以把一个请求的附件拖给同一合并窗口里的另一个请求。作答窗口和历史详情会标记已不存在的附件，并阻止拖出失效文件。
- **托盘图标**：Windows 按系统任务栏主题调整图标明暗；Linux 增加标准 GNOME 深色顶栏和桌面门户主题识别。托盘颜色不再受 AskHuman 窗口主题影响（感谢 @dearrrfish，#17）。
- **多份安装**：增加后台进程互相替换的保护和安装诊断，便于发现 PATH 遮蔽及多份 AskHuman 并存的问题。

### 修复与安全更新

- **macOS 拖入文件**：修复 AskHuman 不在前台时，拖入文件可能首次读取失败、再次拖入才成功的问题。
- **作答窗口**：修复弹窗出现时 Agent 悬浮信息卡自行展开的问题。
- **依赖安全**：更新证书验证、根证书和 ZIP 依赖，解决本次依赖审计中的漏洞通告；DOCX 内容与升级前保持一致。

源码构建的最低 Rust 版本声明调整为 **1.88**，与现有依赖要求一致；使用已编译安装包不受影响。

### Features and improvements

- **History attachments**: Preview attachments beside history details and filter records by attachment presence or file extension.
- **Reply window**: Drag an attachment from one request to another in the same merged window. The reply window and history details mark missing attachments and prevent dragging files that no longer exist.
- **Tray icons**: Follow the Windows taskbar theme and detect standard GNOME dark panels or desktop portal preferences on Linux. Tray colors are independent of the AskHuman window theme (thanks @dearrrfish, #17).
- **Multiple installations**: Add protection against builds repeatedly replacing each other's daemon, plus diagnostics for PATH shadowing and multiple AskHuman installations.

### Fixes and security updates

- **macOS file drops**: Fix an initial file drop failing while AskHuman is in the background, requiring another attempt.
- **Reply window**: Fix the Agent hover card opening by itself when a reply window appears.
- **Dependency security**: Update certificate verification, root certificates, and ZIP dependencies to address the reported dependency vulnerabilities. Generated DOCX contents remain unchanged.

Building from source now declares **Rust 1.88** as the minimum, matching existing dependency requirements. Prebuilt installations are unaffected.
