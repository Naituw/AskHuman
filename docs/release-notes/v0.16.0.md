### 新增与改进

- **Codex 委派运行静默**：由其他 Agent、脚本或插件启动的 Codex 运行（`codex exec`、`review`、官方 Claude Code 插件等）现在表现得和没装 AskHuman 一样：没有工具、没有结束确认、没有权限审批，不会再因为子进程的提问或确认卡住调用方。Codex 的交互协议同时从 `~/.codex/AGENTS.md` 里的托管区块改为由 SessionStart hook 注入。**升级后请在「设置 → Agents」里对 Codex 点一次「更新」完成迁移**（不会自动迁移；需要 Codex 0.144.1 或更新版本，更低版本会提示不支持，原有设置保持不变）。想让委派运行继续使用 AskHuman，可打开同一行的「允许被委派的 Codex 运行使用 AskHuman」（命令行：`AskHuman agents delegated codex on`）。

### 修复

- **Codex 桌面版**：从 AskHuman 新建任务时，沿用目标目录实际生效的模型和推理强度，不再退回应用默认值。
- **作答窗口**：合并窗口里每个请求自己的「取消」只取消该请求（已填写回答时会先确认），不再询问是否取消全部待答请求；关闭窗口（⌘W / Ctrl+W）仍会确认整个窗口。
- **作答窗口**：待答列表下方的空白区域也可以拖动窗口。
- **历史记录**：「历史范围」菜单的项目和会话列表过长时可以滚动，不再被截断；从项目斜着移向它的会话时，不会再因为划过其他项目而跳到别的项目，会话列表顶部会显示所属项目名。
- **MCP**：用本地安装脚本（macOS / Linux）安装新版本时保持已有 MCP 连接，同一 Agent 会话里可以继续提问；以前覆盖安装可能让正在运行的 MCP 进程因代码签名失效被系统终止。

### Features and improvements

- **Silent delegated Codex runs**: Codex runs started by other agents, scripts or plugins (`codex exec`, `review`, the official Claude Code plugin, and so on) now behave as if AskHuman were not installed: no tools, no Stop confirmation and no permission prompts, so a child run no longer stalls the agent that called it. The Codex interaction protocol also moves from the managed block in `~/.codex/AGENTS.md` to a SessionStart hook. **After upgrading, open Settings → Agents and press Update on Codex once to migrate** (it is never migrated automatically; it needs Codex 0.144.1 or newer, and older versions report it as unsupported and keep their current setup). To let delegated runs keep using AskHuman, turn on "Let delegated Codex runs use AskHuman" on the same row (CLI: `AskHuman agents delegated codex on`).

### Fixes

- **Codex Desktop**: Tasks created from AskHuman start with the model and reasoning effort configured for the target directory instead of falling back to the app's defaults.
- **Reply window**: In the merged window, a request's own Cancel button cancels only that request (asking first when you have already written an answer) instead of offering to cancel every pending request. Closing the window (⌘W / Ctrl+W) still confirms for the whole window.
- **Reply window**: The blank area below the request list now drags the window too.
- **History**: Long project and session lists in the history scope menu scroll instead of being cut off. Moving diagonally from a project to its sessions no longer jumps to another project on the way, and the session list shows the owning project's name at the top.
- **MCP**: Installing a new build with the local install script (macOS / Linux) keeps existing MCP connections alive, so the same Agent session can keep asking. Overwriting the binary could previously get running MCP processes killed for an invalid code signature.
