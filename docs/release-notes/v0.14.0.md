### ✨ Features

- **popup**: Answer concurrent questions in one window, with a sidebar for pending questions, project groups, unread indicators, and saved drafts. The combined window is enabled by default; switch back to separate windows in Settings → General → Popup behavior → Question window mode.
- **popup**: Preview attachments beside the question, including images, source code, Markdown, and highlighted diffs and patches. On macOS, use native previews for supported documents and media.
- **popup**: Open rendered Markdown in the default browser.
- **codex**: Create and continue persistent tasks in the macOS Codex desktop app, steer or stop running tasks, and answer supported native questions and approvals through AskHuman. Choose the preferred desktop or CLI runtime in settings, with automatic fallback when one is unavailable.
