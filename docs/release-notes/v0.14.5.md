### 新增与改进

- **Cursor Desktop**：macOS 新增「禁止后台完成后自动续跑（实验）」开关，默认关闭。开启并接入后，后台 Shell / 子代理完成不会自动启动下一轮模型，任务结果、Await 和主动继续仍正常工作。每个窗口先检查兼容性，通过后才显示已生效。已验证 Cursor 3.14.27、3.18.25、3.24.12 的 Agents 和 IDE 窗口；启动和重载有短暂接入过程，终端 Cursor CLI 不在范围内。
- **作答窗口**：会话和项目标签支持悬停查看详情，包括会话标识、可用的模型与上下文信息、项目路径和 Git 摘要；回复图片支持预览。
- **历史记录**：保存结束确认的提问与回答，方便回看，也可通过 `show_last` 找回。

### 修复与安全更新

- **作答窗口**：新问题到达时刷新会话名称，避免继续显示旧标题。
- **Grok 集成**：防止 Cursor 误加载 Grok 的交互 Skill。
- **依赖**：更新 rustls 和 quinn-proto，修复依赖安全审计发现的漏洞。

### Features and improvements

- **Cursor Desktop**: Add an opt-in, experimental macOS setting to prevent background Shell and subagent completions from automatically starting another model turn. Task results, active Await calls, and manual continuation remain available. Each window must pass compatibility checks before becoming active. Verified with Agents and IDE windows in Cursor 3.14.27, 3.18.25, and 3.24.12. Startup and reload have a brief attachment period; terminal Cursor CLI is not covered.
- **Reply window**: Hover over session and project labels to inspect session identities, available model and context information, project paths, and Git summaries. Preview images attached to replies.
- **History**: Save completion-confirmation questions and answers for review, including retrieval through `show_last`.

### Fixes and security updates

- **Reply window**: Refresh session names when new questions arrive.
- **Grok integration**: Prevent Cursor from loading Grok's interaction skill.
- **Dependencies**: Update rustls and quinn-proto to address vulnerabilities reported by dependency auditing.
