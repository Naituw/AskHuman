### Features and improvements

- **iCloud todo sync (experimental, macOS)**: Share project todos and run history between Macs signed in to the same Apple ID. The signed, notarized sync component is included in macOS packages; no Xcode or developer account is needed. Requires macOS 14 or newer and is off by default under Settings → Experimental. Projects match by Git remote; attachments and automatic-run flags stay on their original Mac. See the [setup guide](https://github.com/Naituw/AskHuman/blob/v0.17.0/docs/wiki/todo-sync.en.md).
- **Todos**: Switch projects from a sidebar, browse all projects together, and add a todo to the current project from the reply window with ⌘T.
- **Away mode**: Tell agents you are away from the menu bar, Agent console, Settings or reply window, with a desktop status capsule and a welcome-back summary on macOS. You can also use `AskHuman away on` / `off`, or `/away` / `/back` in IM, and stop using AskHuman for an individual session.
- **Quick replies**: Choose a preset reply in the reply window to answer with one click, and edit the list in Settings.
- **New tasks**: Choose the model, reasoning effort and Codex Fast from desktop task creation. Cursor tasks start with Max mode off unless you allow it, and can optionally be created in Cursor's Agents window (experimental, macOS).
- **Agent failures and messages**: Final failures can raise an error card, including when Cursor gives up after retries. Where supported, ask the original session to continue from the card. You can also message idle or ended Cursor chats directly.
- **Antigravity**: Add CLI and MCP integration on Unix, with CLI recommended.

### Fixes

- **Reply window**: Prevent the reply field from growing cumulatively, stop title-bar clicks from jumping across screens on macOS, and keep idle inboxes expanded for the next request.
- **Repeated questions**: Coalesce identical asks re-sent by an agent, reducing duplicate "what's next" and Stop confirmation cards.
- **Agent console**: Keep failure cards from withdrawing themselves and refresh session titles after a rename.
- **Background service**: Improve update handoff and recovery, and preserve the specific error when startup or status checks fail.
- **Linux**: Stop todo and history watchers from repeatedly re-reading, preserve symlink installation entries, and repair upgrade tracking.
- **Integrations**: Remove obsolete Codex MCP options and preserve Antigravity integration state during updates and recovery.

The iPhone app is distributed separately through TestFlight; its app-only changes are not part of this desktop update.
