### Features and improvements

- **Setup wizard**: The remote-answering step now guides you through the iOS App. A tile shows where you stand (not set up, waiting for a phone, ready, or a broker problem) with the three steps and what you need; its button opens the iOS card in Settings and, if the channel is off, turns it on and opens step 1. Choose "Set up with an Agent" to copy a prompt your Agent can follow. `AskHuman setup --text` offers the same as a fifth choice: it explains the three steps, then runs the channel wizard, a connection test and an offer to pair a phone, or prints the Agent prompt. Setting up only the iOS App now counts as a remote channel, so the step is no longer marked as skipped.
