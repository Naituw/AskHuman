### Features and improvements

- **iOS App channel**: The iPhone channel is no longer experimental: its card moves from Settings → Experimental to Settings → Channels (existing settings and pairings carry over). It walks you through three steps: connect a broker (EMQX Cloud, flespi or self-hosted, with the ports and the points that matter for each), install the iPhone app from TestFlight (iOS 17 or later), and pair a phone. Then send a test question to check that the phone receives it and can answer, or choose "Set up with an Agent" to copy a guide your Agent can follow to do most of it for you. Join the TestFlight beta from the [AskHuman Mobile page](https://naituw.github.io/AskHuman/); the [setup guide](https://github.com/Naituw/AskHuman/blob/v0.18.0/docs/wiki/ios-setup.en.md) has the details.
- **Push relay**: When no relay address is set, pushes go through a public relay, so you no longer need to deploy your own cloud function. It only forwards encrypted pushes and stores nothing (see the [privacy policy](https://naituw.github.io/AskHuman/privacy/)); choose "Use my own relay" on the card to keep control.
- **Test connection**: Also warns when the broker account can read or write topics outside its own.
- **Phone image previews** (needs the latest iPhone app): Large images in the iPhone viewer open from a small preview first; tap "Original" to download the full-size file. Sharing always uses the original, and a file the phone already has is not downloaded again.
- **Local file links**: Links and images that point to local files in a message now open in the side preview panel with the same right-click menu as attachments; Cmd/Ctrl+click opens the file in its own app.

### Fixes

- **Claude Code**: A message you queue for a working session now reaches the main Agent instead of a background sub-agent, and a session stays "working" while a background sub-agent runs, so the finish confirmation no longer appears early.
- **Windows**: Fix garbled non-ASCII text (for example Chinese on a legacy console code page) in Claude Code popups. After upgrading, open Settings → Agents and press Update on Claude Code once; the hook script is never refreshed automatically.
- **Reply window**: Clicking the Dock icon switches to the Space where a popup is open (macOS).
- **Feishu**: Network errors now say why a request failed (connection refused, DNS, proxy, timeout) instead of only "error sending request".
- **Settings**: The Antigravity install note moves into the card's details, so a folded card is as tall as the others.
- **Security**: Network errors from Telegram, DingTalk and Slack no longer include secrets from the request address (a bot token, an access token or a one-time upload address) in the log, the command line or the settings banners. The URL parsing library is updated to 2.5.9, fixing a stack overflow on deeply nested `blob:` URLs (RUSTSEC-2026-0592).
