### 🐞 Fixes

- **daemon,channels**: Keep asking when a popup or IM connection is lost, instead of treating a dropped surface as a user cancel.
- **popup**: Keep find from dragging the viewport back to the current match while scrolling or switching questions.
- **daemon**: Handle SIGTERM as a graceful stop so logout, `kill`, and launchd bootout no longer cut off in-flight requests.
- **daemon**: Serialize daemon startup and skip bootout while a live instance is still running, so concurrent clients do not kill a newly spawned daemon.
- **cli,daemon**: Stop waiting on a drained daemon once its successor is up, so a replacement no longer leaves a CLI polling forever.
