### Features and improvements

- **Extra config directories**: Each integrated Agent can now keep AskHuman in extra config directories besides its main one, for example a custom `CODEX_HOME`, `CLAUDE_CONFIG_DIR`, `GROK_HOME`, `PI_CODING_AGENT_DIR` or `CURSOR_CONFIG_DIR`. Add one in Settings → Agents (inside the Agent's Details) or with `AskHuman agents profile add <agent> <path>`; `AskHuman agents profile` also has `list`, `enable`, `disable`, `remove`, `sync` and `dismiss`. An extra directory follows the Agent's mode and switches, keeps its own record of the files AskHuman wrote, and a missing or hand-edited one never blocks the others.
- **Isolated Antigravity homes** (macOS and Linux): The separate Antigravity homes that an external host creates for its agents are now found read-only and listed under Antigravity's extra config directories with Enable and Ignore. Nothing is written to one until you enable it.
- **Agents launched by an external host**: A session the host delegates to a child thread now stays silent in AskHuman (no cards, hooks, MCP questions, permission prompts or finish confirmations), while the host's main thread keeps everything. Pi also stays out of the way when a host drives it over RPC: no background polling and no Stop confirmation. For the Pi part, open Settings → Agents and press Update on Pi once after upgrading; the extension is never refreshed automatically.
- **History**: The scope button now has a small clear button whenever the history is narrowed to one project or session (for example when it opens on the session of the popup you came from); one click shows everything again. Keyword and attachment filters keep their own clear controls.

### Fixes

- **Agents**: Sessions that run under a custom config directory or are launched by an external host (Antigravity over ACP, for example) now get their title, activity, `/transcript`, last message on Stop and sub-agent folding like any other session. One shared `agy acp` process no longer ends its live sessions early, and a host's own prompt wrappers no longer end up in session titles or `/transcript`.
- **Security**: Update the cookie library to 0.18.3 (RUSTSEC-2026-0594). It is a dependency of the app framework and AskHuman's own code does not use it.

The iPhone app is distributed separately through TestFlight; its app-only changes are not part of this desktop update.
