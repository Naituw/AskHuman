### Features and improvements

- **Unsent replies**: If an ask is cancelled while you are still typing in the reply window, for example when an Agent such as Cursor errors out and drops its connection, your text, notes and pictures are no longer lost. They are kept as a draft on that entry in History, and asking the same question again in the same session loads the draft once, with a notice you can dismiss. The History window marks entries that carry a draft and lets you search and copy it. Pictures in a draft are kept for about a day.
- **Antigravity** (macOS App and `agy` CLI; verified on macOS only): Sessions are tracked in the Agent console under their real conversation, the Stop confirmation can send an Agent back to work, you can queue a message to a working session or wake an idle one, and Watch and IM live views show its latest text, tools and thinking. Phone, IM and the New Task window can start Antigravity tasks, in the App through a per-folder sidecar (managed in Settings or with the `AskHuman` command line) or in a terminal with `agy`. Rules, MCP and hooks are now installed as one AskHuman plugin; the old shared rules are migrated the first time you run `AskHuman agents update antigravity` after upgrading.
- **Todos**: Complete, delete and add todos right in the todo lists of a question, What's next and the Stop confirmation; ⌘T / Ctrl+T adds one.
- **What's next**: Pick several next tasks at once.
- **Agent settings**: Set the collaboration style per Agent, with a default style for the Agents that follow it.
- **Cursor**: Opt-in "report, then end" while you are away: an Agent's reasoned escalation is saved as an unread report and the Agent ends its turn instead of waiting. Session protection (experimental) now gives parallel agents isolated HTTP/2 connections.
- **Updates**: Skip a version from the update prompt.
- **Agent console**: The latest text of an expanded Agent refreshes by itself, and no longer stays frozen after you click or scroll near it.
- **iPhone channel**: Mac settings say plainly when this month's data use is close to a GB, traffic is counted per device instead of doubling one Mac's total, starting a task from the phone can offer up to 300 todos, and live agent views no longer resend unchanged text (less data; needs the next iPhone app update).

### Fixes

- **Reply window**: A single question with attached files now shows its text in the message area, so you can add notes to it. Continuous scrolling stays inside popup panes, and popups exit quietly when the system session ends.
- **Popups and background service**: Popup hosts no longer pile up as defunct processes after an update, hosts that never authenticate or do not reconnect are ended, a cancelled ask no longer comes back as a ghost card, and an idle popup host kept across an update is replaced by the new one. Popups recover after macOS login transitions, and false recovery warnings are avoided.
- **Daemon and channels**: Handshakes are bounded and a daemon that stops answering is replaced, Status is answered while an IM router is still connecting, an unreadable binary no longer counts as a changed one, WebSocket handshakes of long-connection routers are bounded, Slack ignores a card submit from another conversation, and system instances resolve their paths from the account home.
- **Agents**: Restore Codex desktop task creation, fix a false phone warning about a message to an idle Codex chat, keep Cursor session protection active without the Agent Host and after app updates, allow messaging through any available session channel, and honor "disable for this session" replies in the interaction rules.
- **Security**: Update bundled SQLite and the MCP SDK.

The iPhone app is distributed separately through TestFlight; its app-only changes are not part of this desktop update.
