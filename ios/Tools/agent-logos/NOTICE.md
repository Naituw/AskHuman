# Agent logos

The marks of the Agents the iOS app shows next to their requests and sessions. They only identify
the Agent a request comes from; the names and marks belong to their owners (Anthropic, Anysphere,
OpenAI, xAI and the Pi project) and AskHuman is not affiliated with any of them.

| File | Mark | Source |
|---|---|---|
| `claude.svg` | Claude | [LobeHub Icons](https://github.com/lobehub/lobe-icons) `claude` |
| `cursor.svg` | Cursor | LobeHub Icons `cursor` |
| `codex.svg` | Codex | LobeHub Icons `codex` |
| `grok.svg` | Grok | LobeHub Icons `grok` |
| `pi.svg` | Pi | The official logo from https://pi.dev/logo-auto.svg, cropped to its bounds |

`make-logos.sh` turns the sources into the vector assets in
`ios/AskHuman/Resources/Assets.xcassets/AgentLogos`.
